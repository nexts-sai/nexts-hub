# Remotion for Nexts

Install this package through Nexts Hub and enable its skills. Requires Node.js 20+ and npm on PATH.

Load remotion-best-practices, then the relevant creation, Studio or render skill. Install project dependencies in the video workspace. Studio preview and rendering require local browser/runtime dependencies; this package does not bundle the Remotion runtime. Remotion runtime licensing remains separate from the skill package license.

See NOTICE.nexts.md and UPSTREAM.json for attribution and adaptation details.
