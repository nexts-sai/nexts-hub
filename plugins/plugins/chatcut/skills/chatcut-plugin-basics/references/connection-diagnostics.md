# Nexts connection diagnostics

Check the enabled plugin contribution, the npx executable, and the exact error reported by Nexts. Missing executable/download failure is a local runtime problem; 401 is an authentication problem. Complete the browser OAuth flow and retry discovery once. If initialization timed out while signing in, reconnect after sign-in. Check that the selected tools belong to this plugin's OAuth bridge rather than a separate manually configured chatcut HTTP entry.

Preserve the error without tokens or signed URLs. Do not read Codex configuration, browser profiles, chat transcripts or unrelated logs. Do not upload diagnostics automatically or disable TLS verification. If OAuth fails, report the specific step and retain the existing configuration; do not repeatedly reinstall or delete the entire OAuth cache.
