# FilmCraft explainer

Use for tutorials, product walkthroughs, lessons, demos, and technical explainers. Read [editorial techniques](../../references/editing-techniques.md) and [FilmCraft editing](../filmcraft-edit/SKILL.md).

## Editorial plan

- Define the learner's question, prerequisite knowledge, outcome, and chapter order before cutting.
- Use question -> explanation -> demonstration -> recap. Keep each segment focused on one concept and show the exact screen, object, or diagram being discussed.
- Remove repeated explanations and dead time, but preserve context required to reproduce the steps. Use cursor emphasis, callouts, zooms, highlights, and step cards only where they reduce cognitive load.
- Keep narration, screen action, cursor position, captions, and diagrams synchronized. Use chapter cards for structure, not decoration.

## Execution

1. Inspect the source and create a chapter map with claims and evidence.
2. Build a narration or dialogue-first cut, then align the visual demonstration.
3. Add step cards, callouts, cursor or crop emphasis, captions, and restrained transitions in passes.
4. Discover FilmCraft MCP commands before each mutation and inspect the timeline and object IDs after each pass.
5. Review reproducibility, caption timing, visual legibility, audio clarity, and the final recap before export.

Do not hide missing steps with fast motion, decorative graphics, or an unsupported automation claim.
