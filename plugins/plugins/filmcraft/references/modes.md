# Video modes

## Product short (initial template)
Opening product context → one demonstrated benefit → closing product shot. Default to 15 seconds and 9:16 only when the user has no delivery constraints. Keep the product geometry/material consistent. Avoid invented claims. Narration should leave pauses; narration duration determines the minimum shot length.

## Explainer
Question → explanation in short visual units → recap. Prefer diagrams or clear demonstration footage over unrelated decorative shots. Keep terminology consistent between voice and captions.

## Narrative
Define character/scene continuity, action beats and shot-reverse relationships before generation. Reuse reference images and avoid treating independent prompts as continuity control. Review each shot before spending on dependent shots.

New modes reuse the same asset receipts, frame-based production contract and FilmCraft adapter. Add only mode-specific choices here; do not duplicate transport or retry logic.
