# FilmCraft 0.2.3 Unified Acceptance

Install the consolidated ZIP once and enable FilmCraft. Use natural app mentions, not internal skill names. Inspect actual model skill loads/tool arguments and the visible timeline, saved project and requested artifacts. This checklist does not claim deterministic routing or completed runtime tests.

Use disposable projects with consented presenter footage, a long topic-rich lecture, two cameras/recorder with known offsets, B-roll with edge text, a short music bed and existing captions. Keep originals and real timestamp evidence. Private fixtures/logs stay outside the package and account service.

## Failure and continuation

- Plain-text-only ASR: untimed transcript/plan allowed; no guessed cuts or synchronized captions.
- Unsupported schema: refresh and specific blocker; no ChatCut payload or FFmpeg edit fallback.
- Partial batch: inspect successful operations; resume remaining work without duplicates.
- Pending ASR/render: continue authorized stages with progress; submission is not completion.
- Ambiguous timeout: inspect existing jobs before resubmitting.
- Unexpected project switch/concurrent writer: pause mutations and preserve others' edits.
- Interrupted multi-version task: retain completed versions and resume incomplete outputs.
- Missing media/model, no speech, bridge refusal, failed render and cancellation: distinct states, no broad automatic restart.

Record per case: request, selected skills, target ids, relevant arguments, actual outcome, structural/visual/audio evidence and unresolved failures in local QA notes. Verify save/reopen persistence and exported pixels/audio before accepting a runtime pass. Static authoring and synthetic adapter/arithmetic checks do not prove live editing quality.
