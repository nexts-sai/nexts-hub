## Genre composition

These genre templates predate this adaptation and are Nexts-authored, not claimed ChatCut originals. Genre suggestions do not authorize every finishing technique.

| Goal | Main workflow | Supporting techniques when requested |
|---|---|---|
| Presenter/tutorial cleanup | [Talking-head](../skills/filmcraft-talking-head/SKILL.md) | Captions, B-roll, graphics, audio |
| Interview/podcast/documentary | [Interview](../skills/filmcraft-interview/SKILL.md) | Story editing, multicam, shorts, captions |
| Product short | [Product short](../skills/filmcraft-product-short/SKILL.md) | Hook, demonstration cutaways, titles, audio |
| Promo/trailer | [Promo](../skills/filmcraft-promo/SKILL.md) | Narrative order, visual proof, effects, audio |
| Explainer | [Explainer](../skills/filmcraft-explainer/SKILL.md) | Chapters/diagrams, B-roll, narration sync, captions |
| Music-led/travel/event montage | [Montage](../skills/filmcraft-montage/SKILL.md) | Measured beat decisions, visual continuity, effects, audio |

A topic-based two-camera interview with subtitles uses multicam alignment -> story selection/reordering -> derived angle edit -> captions -> verification -> requested export. A subtitles-only interview skips editorial changes. Music-only work preserves the cut. A short version is not automatically vertical.

Shared stages: [import/relink](../skills/filmcraft-import/SKILL.md), [transcription](../skills/filmcraft-transcription/SKILL.md), [verification](../skills/filmcraft-verify/SKILL.md), [export](../skills/filmcraft-export/SKILL.md).

## Source and capability boundary

Source-derived techniques map to actual pinned ChatCut grok originals in [provenance](chatcut-adaptation/README.md), with original bytes/license. Host lifecycle, dependency discovery and continuation are Nexts adaptations. Skills do not add missing native editor capabilities.

Avatar creation, voice cloning, lip-sync rendering, dubbing services, hosted upload widgets and ChatCut account APIs are outside this editing-technique release. Existing Nexts image/video/TTS production remains separate; it is not equivalent to unavailable specialized services.
