# HyperFrames by HeyGen for Nexts

Install this package through Nexts Hub and enable its skills. Requires Node.js 20+ and npm on PATH.

Use skills/hyperframes/scripts/plugin-cli.mjs from the video project directory; it downloads the CLI version matching this manifest. Outputs and dependencies belong to the project, never the plugin package. Provider login/paid features remain separate.
