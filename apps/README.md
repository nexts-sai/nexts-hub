# NEXTS Applications

This category contains application metadata and action schemas used by the Nexts application marketplace.

- Source entries: `apps/apps/<service>.json`
- Generated registry: `apps/.agents/apps/marketplace.json`
- Regenerate and validate with `npm run sync` and `npm run validate`.

MCP server launch definitions remain under `mcp/<id>/mcp.json`; adapter runtime source remains under `mcp/_adapters`.
